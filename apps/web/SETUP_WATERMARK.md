# 🎨 Guía de Configuración: Marca de Agua del Dashboard

## Inicio Rápido (3 pasos)

### Paso 1: Acceder a Configuración
```
1. Haz click en tu avatar (esquina inferior izquierda)
2. Selecciona "Configuración del Sistema"
3. Haz click en la pestaña "Marca y Marca de Agua"
```

### Paso 2: Subir Logo
```
1. En la sección "Logo de la Empresa"
2. Haz click en el área de carga o arrastra tu logo
3. Espera la confirmación de carga exitosa
```

### Paso 3: Configurar Marca de Agua
```
1. Activa el toggle "Mostrar Marca de Agua"
2. Ajusta la opacidad (5-50%) con el deslizador
3. Selecciona la posición preferida
4. Haz click en "Guardar Configuración"
```

## ✅ Requisitos

- **Logo**: JPG, PNG, SVG o WEBP (máximo 5 MB)
- **Recomendación**: PNG o SVG con transparencia
- **Acceso**: Solo Super Administrador

## 🎯 Opciones de Configuración

### Opacidad
- **5-15%**: Muy sutil, casi invisible
- **15-25%**: Visible pero no obstruye contenido
- **25-50%**: Muy visible, ideal para branding fuerte

### Posiciones (9 opciones)

```
┌─────────────────────────────────┐
│ Arriba   │ Arriba  │ Arriba     │
│ Izquierda│ Centro  │ Derecha    │
├─────────────────────────────────┤
│ Centro   │         │ Centro     │
│ Izquierda│ CENTRO  │ Derecha    │
├─────────────────────────────────┤
│ Abajo    │ Abajo   │ Abajo      │
│ Izquierda│ Centro  │ Derecha    │
└─────────────────────────────────┘
```

## 🎨 Personalización de Colores

En la misma sección, puedes personalizar:
- **Color de Fondo**: Fondo del dashboard
- **Color Primario**: Botones principales
- **Color Secundario**: Elementos secundarios
- **Color de Acento**: Badges y acentos

### Usar Color Picker
```
1. Haz click en el cuadrado de color
2. Selecciona el color deseado
3. O ingresa el código HEX directamente
4. Guarda los cambios
```

## 💡 Mejores Prácticas

### Para un Logo Óptimo
✅ Use PNG transparente para mejor integración
✅ Asegúrese que el logo sea legible a diferentes opacidades
✅ Logos cuadrados o rectangulares funcionan mejor
✅ Evite logos muy complejos o con muchos detalles

### Para Marca de Agua Efectiva
✅ Opacidad 15-20% es la más equilibrada
✅ Posición central es la más clásica
✅ Esquinas inferiores no obstruyen contenido
✅ Combine con colores corporativos para consistencia

## 🔄 Cambios en Tiempo Real

Cuando guardas la configuración:
1. Se actualiza la base de datos
2. La página se recarga automáticamente
3. Los cambios aparecen inmediatamente en el dashboard
4. Todos los usuarios ven los cambios sin necesidad de recargar

## ❌ Problemas Comunes

### "El logo no se ve"
**Solución:**
- Verifica que el toggle esté activado (verde)
- Intenta cambiar la opacidad
- Recarga la página manualmente

### "Los colores no se aplican"
**Solución:**
- Guarda explícitamente la configuración
- Limpiar caché del navegador (Ctrl+Shift+Del)
- Recarga completamente (Ctrl+F5)

### "El logo se ve muy pequeño/grande"
**Solución:**
- Los logos se adaptan automáticamente
- Probá con un logo de mayor resolución
- El sistema redimensiona automáticamente

### "La marca de agua obstruye contenido"
**Solución:**
- Reduce la opacidad (más transparente)
- Cambia la posición a esquina
- Usa opción "Centro Izquierda" o "Centro Derecha"

## 📊 Valores Recomendados

### Para Empresa Grande
```
Opacidad: 10-15% (sutil)
Posición: Centro
Logo: Blanco/Transparente
```

### Para Empresa Pequeña
```
Opacidad: 20-25% (visible)
Posición: Abajo Derecha
Logo: Color (mayor visibilidad)
```

### Para Branding Fuerte
```
Opacidad: 30-40% (muy visible)
Posición: Centro
Logo: Color principal
```

## 🔐 Consideraciones de Seguridad

- Solo Super Administrador puede cambiar configuración
- Archivos se validan antes de subir
- URLs relativas para mejor portabilidad
- Cambios se registran en la base de datos
