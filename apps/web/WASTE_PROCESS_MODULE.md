# Módulo de Venta de Proceso y Desecho - Tecavo Soft\n\n## Descripción General\n\nEl **Módulo de Venta de Proceso y Desecho** es un sistema completo e integrado para gestionar la venta de productos derivados de la lotificación (pulpa, chips, desecho procesado). Incluye tres componentes principales:\n\n1. **Pesada Integrada** - Conexión en tiempo real con balanzas externas\n2. **Precios de Venta** - Cálculo automático de precios basado en cantidad y precio unitario\n3. **Impresoras de Ticket** - Generación de folio único e irrepetible con impresión automática\n\n---\n\n## Arquitectura del Sistema\n\n### Base de Datos\n\n**Tabla Principal:** `sales_of_process_and_waste`\n\n```sql\nCOLUMNS:\n- id (SERIAL PRIMARY KEY)\n- lot_id (INTEGER) - Referencia al lote origen\n- lotification_record_id (INTEGER) - Referencia al registro de lotificación\n- buyer_name (TEXT) - Nombre del comprador\n- destination (TEXT) - Destino de envío\n- date (DATE) - Fecha de la venta\n- source_batch_number (TEXT) - Folio del lote fuente\n- sales_folio (TEXT UNIQUE) - Folio automático único de venta (VENTA-0001, VENTA-0002, etc.)\n- product_name (TEXT) - Tipo de producto (Pulpa, Chips, Desecho Procesado)\n- process_kg (NUMERIC) - Kilogramos de producto procesado\n- waste_kg (NUMERIC) - Kilogramos de desecho\n- shrinkage_kg (NUMERIC) - Kilogramos de merma (pérdida)\n- unit_price (NUMERIC) - Precio por kilogramo\n- total_price (NUMERIC) - Precio total manual\n- calculated_price (NUMERIC) - Precio calculado automáticamente (process_kg × unit_price)\n- notes (TEXT) - Observaciones\n- created_at (TIMESTAMP)\n- updated_at (TIMESTAMP)\n```\n\n### API Routes\n\n#### 1. **GET/POST/PUT/DELETE** - `/api/sales-process-waste`\n\n**GET** - Obtiene todos los registros o filtrado por lote\n```javascript\nFetch Parameters:\n- ?lotId=123 (opcional) - Obtiene solo ventas de ese lote\n\nResponse:\n[\n  {\n    id: 1,\n    sales_folio: \"VENTA-0001\",\n    buyer_name: \"Exportadora ABC\",\n    destination: \"USA\",\n    process_kg: 500,\n    waste_kg: 50,\n    shrinkage_kg: 10,\n    unit_price: 2.50,\n    calculated_price: 1250.00,\n    lot_number: \"LOT-2024-001\",\n    producer: \"Juan Pérez\",\n    fruit_type: \"Mango Ataulfo\",\n    ...\n  }\n]\n```\n\n**POST** - Crea nuevo registro de venta\n```javascript\nPayload:\n{\n  lotId: 123,\n  lotificationRecordId: 45,\n  buyerName: \"Exportadora ABC\",\n  destination: \"USA\",\n  date: \"2024-01-15\",\n  sourceBatchNumber: \"LOT-2024-001\",\n  salesFolio: \"VENTA-0001\", // Auto-generado si es vacío\n  productName: \"Pulpa\",\n  processKg: 500,\n  wasteKg: 50,\n  shrinkageKg: 10,\n  unitPrice: 2.50,\n  totalPrice: \"\", // Se calcula automáticamente\n  notes: \"Envío refrigerado\"\n}\n```\n\n**PUT** - Actualiza registro existente\n```javascript\nPayload: {id: 1, ...datos actualizados}\n```\n\n**DELETE** - Elimina registro\n```javascript\nURL: /api/sales-process-waste?id=1\n```\n\n#### 2. **GET** - `/api/sales-process-waste/next-folio`\n\nObtiene el próximo folio único disponible\n\n```javascript\nResponse:\n{\n  nextFolio: \"VENTA-0001\" // O VENTA-0002, VENTA-0003, etc.\n}\n```\n\n**Lógica de Generación:**\n- Busca el último folio registrado con patrón `VENTA-XXXX`\n- Si no existe, inicia con `VENTA-0001`\n- Incrementa el número en 1\n- Rellena con ceros a la izquierda hasta 4 dígitos\n- **Garantiza folios únicos e irrepetibles** (validados en BD)\n\n#### 3. **POST** - `/api/sales-process-waste/print-ticket`\n\nGenera y envía ticket a la impresora térmica\n\n```javascript\nPayload:\n{\n  recordId: 1, // ID del registro de venta\n  printerId: 5 // ID de la impresora (opcional, usa default si no se especifica)\n}\n\nResponse:\n{\n  success: true,\n  message: \"Ticket enviado a la impresora\",\n  ticket: \"[CONTENIDO DEL TICKET]\",\n  printer: {\n    name: \"Impresora Térmica 80mm\",\n    type: \"Thermal\",\n    connection: \"Network\"\n  }\n}\n```\n\n**Formato del Ticket (Térmica 80mm):**\n```\n==========================================\n          TECAVO SOFT\n   Venta de Proceso y Desecho\n==========================================\n\n          FOLIO: VENTA-0001\n\nFecha:   15/01/2024\nHora:    10:30:45\n------------------------------------------\n\nINFORMACION DE ORIGEN\n------------------------------------------\nLote:        LOT-2024-001\nProductor:   Juan Pérez\nFruta:       Mango Ataulfo\nLote Fuente: LOT-2024-001\n\nDETALLES DE VENTA\n------------------------------------------\nComprador:   Exportadora ABC\nDestino:     USA\nProducto:    Pulpa\n\nCANTIDADES\n------------------------------------------\nKg Proceso:  500.00 kg\nKg Desecho:   50.00 kg\nKg Merma:     10.00 kg\n\nPRECIOS\n------------------------------------------\nPrecio/Kg:   $2.50/kg\n==========================================\nTOTAL A PAGAR: $1250.00\n==========================================\n\nOBSERVACIONES\n------------------------------------------\nEnvío refrigerado\n\n---\n           Gracias por su compra\n\n        Sistema TECAVO SOFT\n\n```\n\n---\n\n## Componentes Frontend\n\n### Página Principal\n**Ruta:** `/app/sales-process-waste/page.jsx`\n\n#### Características:\n\n**1. Usuario hace click en \"Nuevo Registro\"\n   ↓\n2. Sistema obtiene próximo folio automático (/api/sales-process-waste/next-folio)\n   ↓\n3. Usuario llena formulario:\n   - Selecciona lote de origen\n   - Selecciona registro de lotificación (auto-completa desecho/merma)\n   - Ingresa datos del comprador y destino\n   - Ingresa cantidad de kg procesado\n   - (Si escala conectada) Presiona botón para capturar peso\n   - Ingresa precio unitario\n   - Sistema calcula precio total = Kg Proceso × Precio/Kg\n   ↓\n4. Usuario presiona \"Crear Registro\"\n   ↓\n5. Sistema valida campos obligatorios\n   ↓\n6. Sistema guarda en BD (/api/sales-process-waste POST)\n   ↓\n7. Si impresora seleccionada:\n   - Sistema genera ticket (/api/sales-process-waste/print-ticket)\n   - Impresora térmica imprime automáticamente\n   ↓\n8. Sistema obtiene próximo folio para siguiente registro\n   ↓\n9. Formulario se limpia y lista se actualiza\n   ✓ COMPLETADO\n```\n\n### Flujo 2: Pesada Integrada con Escala Externa\n\n```\n1. Sistema detecta escala conectada (via useScaleDevice hook)\n   ↓\n2. Usuario expande \"Panel de Pesada en Tiempo Real\"\n   ↓\n3. Hook recolecta lecturas de peso en tiempo real\n   ↓\n4. Panel muestra:\n   - Peso actual (grande y visible)\n   - Max, Min, Promedio\n   - Número de lecturas capturadas\n   - Gráfico de línea con historial\n   ↓\n5. Usuario presiona \"Usar peso actual: XXX.XX kg\"\n   ↓\n6. Campo \"Kg Proceso\" se auto-completa con peso\n   ↓\n7. Panel se colapsa\n   ✓ LISTO PARA CONTINUAR\n```\n\n### Flujo 3: Impresión de Ticket con Folio Único\n\n```\n1. Usuario selecciona impresora en dropdown\n   ↓\n2. Usuario crea nuevo registro\n   ↓\n3. Sistema guarda registro en BD\n   ↓\n4. Sistema extrae recordId del registro creado\n   ↓\n5. Sistema llama POST /api/sales-process-waste/print-ticket\n   Payload: {recordId: 1, printerId: 5}\n   ↓\n6. API Route:\n   - Obtiene datos completos del registro\n   - Obtiene configuración de impresora\n   - Genera ticket en formato thermal (80mm)\n   - Incluye folio único VENTA-0001\n   - Envía a impresora (network/serial/USB)\n   ↓\n7. Impresora térmica imprime ticket\n   ✓ FOLIO IRREPETIBLE IMPRESO\n```\n\n### Flujo 4: Editar Registro Existente\n\n```\n1. Usuario presiona botón \"Editar\" en tarjeta\n   ↓\n2. Formulario se abre y pre-completa con datos\n   ↓\n3. Usuario modifica campos necesarios\n   ↓\n4. Presiona \"Actualizar Registro\"\n   ↓\n5. Sistema guarda cambios (/api/sales-process-waste PUT)\n   ↓\n6. NO genera nuevo ticket (es edición)\n   ↓\n7. Usuario puede reimprimir ticket si necesita\n   ✓ ACTUALIZADO\n```\n\n---\n\n## Integraciones\n\n### 1. Integración con Pesadas\n\n**Hook:** `useScaleDevice` (ubicado en `/hooks/useScaleDevice.js`)\n\n```javascript\nconst { weight, isConnected } = useScaleDevice();\n```\n\n**Propiedades:**\n- `weight` (number) - Peso actual leído de la escala\n- `isConnected` (boolean) - Estado de conexión de la escala\n\n**Comportamiento:**\n- Se actualiza en tiempo real cuando hay cambios de peso\n- Si no hay escala conectada, usa valores por defecto (0)\n- Permite capturar múltiples lecturas en array\n\n### 2. Integración con Lotes\n\n**API:** `/api/lots`\n\n- Obtiene lista de lotes disponibles\n- Usuario selecciona lote de origen\n- Vincula venta a lote específico para trazabilidad\n\n### 3. Integración con Lotificación\n\n**API:** `/api/lotification`\n\n- Obtiene registros de lotificación\n- Auto-completa `waste_kg` y `shrinkage_kg` con datos de lotificación\n- Permite vinculación bidireccional\n\n### 4. Integración con Impresoras\n\n**API:** `/api/printer-settings`\n\n- Obtiene lista de impresoras configuradas\n- Permite seleccionar impresora objetivo\n- Usa impresora predeterminada si no se especifica\n\n### 5. Integración con Lotes (Batch Tracking)\n\n- Datos de venta aparecen en módulo de Trazabilidad\n- Se usa para calcular ganancia/pérdida por lote\n- Contribuye a reportes de rentabilidad\n\n---\n\n## Validaciones y Seguridad\n\n### Validaciones de Formulario\n- Folio de venta es ÚNICO (constraint en BD)\n- Campos requeridos: Comprador, Producto, Kg Proceso, Precio/Kg\n- Cantidades deben ser números positivos\n- Fecha no puede ser futura\n\n### Validaciones de Ticket\n- Solo se imprime si hay impresora seleccionada\n- Verifica que impresora está activa\n- Genera folio en secuencia atomáticamente\n\n### Prevención de Duplicados\n- Folio único en BD (UNIQUE constraint)\n- Sistema obtiene próximo folio ANTES de mostrar formulario\n- Incremento secuencial sin saltos\n\n---\n\n## Reportes y Análisis\n\n### Datos Disponibles para Análisis\n\n```javascript\n// Desde /api/sales-process-waste\n- Total de ventas por período\n- Volumen total vendido (kg)\n- Ingresos totales\n- Precio promedio por kg\n- Productos más vendidos\n- Compradores más frecuentes\n- Destinos principales\n```\n\n### Integración con Módulo de Trazabilidad\n\nLos datos de venta se integran automáticamente en:\n- Dashboard de Trazabilidad de Lotes\n- Cálculo de ganancia/pérdida por lote\n- Reportes de rentabilidad\n- Timeline completo del lote\n\n---\n\n## Configuración Técnica\n\n### se dispara correctamente\n**Solución:** Recarga página o limpia caché del navegador\n\n### Problema: Escala no se conecta\n**Causa:** Configuración incorrecta en useScaleDevice\n**Solución:** Revisa configuración de puerto/baud rate en settings\n\n### Problema: Impresora no recibe ticket\n**Causa:** Impresora no configurada o inactiva\n**Solución:** Verifica en módulo de Impresoras que está activa\n\n### Problema: Cálculo de precio incorrecto\n**Causa:** Valores ingresados como strings en lugar de numbers\n**Solución:** Sistema convierte automáticamente con parseFloat()\n\n---\n\n##
