# Módulo de Venta de Proceso y Desecho - Resumen Ejecutivo\n\n## 📊 Módulo Completo y Funcional\n\nEl **Módulo de Venta de Proceso y Desecho** es un sistema integrado para gestionar la venta de productos derivados de la lotificación (pulpa, chips, desecho procesado). \n\n**Estado:** ✅ **LISTO PARA PRODUCCIÓN**\n\n---\n\n## 🎯 Tres Componentes Integrados\n\n### 1️⃣ **Pesada Integrada** ⚖️\n\n**Panel de Pesada en Tiempo Real**\n\n- ✅ Conexión automática con balanzas externas\n- ✅ Muestra peso actual en tiempo real\n- ✅ Historial gráfico de últimas 20 lecturas\n- ✅ Estadísticas: máximo, mínimo, promedio\n- ✅ Auto-completa campo \"Kg Proceso\" con peso seleccionado\n- ✅ Se activa solo si escala está conectada\n\n**Integración:**\n- Hook: `useScaleDevice()` ← Detecta escala automáticamente\n- Recibe peso en tiempo real\n- Almacena historial en estado local\n- Permite múltiples lecturas antes de usar\n\n**Uso:**\n1. Sistema detecta escala conectada (muestra indicador 🟢)\n2. Usuario expande panel \"Panel de Pesada en Tiempo Real\"\n3. Observa peso actual y estadísticas\n4. Presiona \"Usar peso actual: XXX.XX kg\"\n5. Campo se auto-completa automáticamente ✓\n\n---\n\n### 2️⃣ **Precios de Venta** 💰\n\n**Sección de Información de Precios (Auto-Calculada)**\n\n- ✅ Campo de precio unitario ($/kg)\n- ✅ **Cálculo automático** de precio total\n- ✅ Validación de números positivos\n- ✅ Precisión a 2 decimales\n- ✅ Capacidad de sobrescribir con precio manual\n\n**Fórmula de Cálculo:**\n```\nPrecio Total = Kg Proceso × Precio por Kg\n\nEjemplo:\n800 kg × $3.50/kg = $2,800.00\n```\n\n**Características:**\n\n- **Cálculo Automático:** Se actualiza mientras escribes\n- **Cartel Resumen:** Muestra cálculo con formula completa\n- **Campo Editable:** Puedes sobrescribir si necesitas\n- **Precisión:** Redondeo a 2 decimales automático\n\n**Integración con Lotificación:**\n\n- Auto-completa \"Kg Desecho\" y \"Kg Merma\" desde registro de lotificación\n- Vinculación automática de lote\n- Se usa para cálculos en módulo de Trazabilidad\n\n---\n\n### 3️⃣ **Printer Integration** 🖨️\n\n**Generación de Tickets con Folio Único e Irrepetible**\n\n#### Folio Único (Sistema Anti-Duplicados)\n\n- ✅ Patrón: `VENTA-0001`, `VENTA-0002`, ... `VENTA-9999`, `VENTA-10000`\n- ✅ Generado automáticamente (no manual)\n- ✅ Garantizado único en BD (UNIQUE constraint)\n- ✅ Incremento secuencial sin saltos\n- ✅ Irrepetible incluso si registro se edita o elimina\n\n**Generación de Folio:**\n\n```\n1. Sistema obtiene folio automáticamente\n   GET /api/sales-process-waste/next-folio\n   ↓\n2. API busca último folio en BD\n   SELECT MAX(sales_folio) FROM sales_of_process_and_waste\n   ↓\n3. Incrementa número + 1\n   Último: VENTA-0001 → Próximo: VENTA-0002\n   ↓\n4. Rellena con ceros\n   1 → \"0001\"\n   ↓\n5. Retorna: VENTA-0002\n   ✓ Único garantizado\n```\n\n#### Selección de Impresora\n\n- ✅ Dropdown con impresoras configuradas\n- ✅ Indica impresora predeterminada\n- ✅ Opción de \"Sin impresora\"\n- ✅ Confirma si se imprimirá automáticamente\n\n**Tipos de Impresoras Soportadas:**\n- Impresoras térmicas 80mm (estándar)\n- Impresoras térmicas 58mm\n- Impresoras de rol\n- Conexión: Red (IP), USB, Serial\n\n#### Impresión Automática de Ticket\n\n- ✅ Se imprime automáticamente al guardar registro\n- ✅ Folio único incluido en cada ticket\n- ✅ Formato optimizado para impresoras térmicas\n- ✅ Incluye toda la información de la venta\n- ✅ Puede reimprimir ticket en cualquier momento\n\n**Contenido del Ticket:**\n\n```\n════════════════════════════════════════\n            TECAVO SOFT\n   Venta de Proceso y Desecho\n════════════════════════════════════════\n\n          FOLIO: VENTA-0001 ← ÚNICO\n\nFecha:   15/01/2024\nHora:    10:30:45\n────────────────────────────────────────\n\nINFORMACION DE ORIGEN\n────────────────────────────────────────\nLote:        LOT-2024-001\nProductor:   Juan Pérez\nFruta:       Mango Ataulfo\nLote Fuente: LOT-2024-001\n\nDETALLES DE VENTA\n────────────────────────────────────────\nComprador:   Exportadora ABC\nDestino:     USA\nProducto:    Pulpa\n\nCANTIDADES\n────────────────────────────────────────\nKg Proceso:  800.00 kg\nKg Desecho:  150.00 kg\nKg Merma:     50.00 kg\n\nPRECIOS\n────────────────────────────────────────\nPrecio/Kg: refrigerado\n\n───────────────────────────────────────\n       Gracias por su compra\n        Sistema TECAVO SOFT\n═════════════════════════════════════════\n```\n\n**Configuración de Impresoras:**\n\nLas impresoras se configuran en:\n`Dashboard → Avatar → Configuración del Sistema → Impresoras`\n\n---\n\n## 📁 Archivos del Módulo\n\n### Código (5 archivos
